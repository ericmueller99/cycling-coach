# Roadmap

Rough order, no dates. Open an issue if you want to help with one.

- **Mobile apps:** iOS and Android through Capacitor, against the same API (the web app is already a
  home-screen app).
- **Garmin:** structured workouts for outdoor rides through intervals.icu.
- **Food:** questions over longer food-log ranges, and adaptive TDEE once there's enough logged data.
- **Sign-in:** email (verification, password reset) for self-host through an SMTP option.
